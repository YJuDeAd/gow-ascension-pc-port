## The 5 Inviolable Project Laws

All agents (Claude Opus 4.6, Gemini Flash 3.8 High, Antigravity, subagents, and tools) MUST strictly obey these 5 laws:

### LAW 1 (Graphify & Porting Guide First)
Always query `graphify query "<question>"` and check `./ps3recomp/docs/GAME_PORTING_GUIDE.md` and `./twistedmetal/` before inventing build scripts, NID macros, or HLE handlers.
- ps3recomp and the Twisted Metal port have already solved numerous common PS3 recompilation hurdles (e.g., FIOS threading/deadlocks, SPURS taskset registration, GCM buffers, RSX shaders, audio callbacks).
- Never write ad-hoc stubs without verifying existing patterns in `./ps3recomp/include/` and `./twistedmetal/src/`.

### LAW 2 (Read-Only Sub-Repos)
Treat `./ps3recomp/` and `./twistedmetal/` as read-only reference repositories unless explicitly building `ps3recomp_runtime.lib`.
- All God of War: Ascension port files live in `./src/`, `./tools/`, `./docs/`, and `./CMakeLists.txt` in the root workspace.
- Do not modify files in `./ps3recomp/` or `./twistedmetal/`. Any necessary runtime overrides or monkeypatches must be implemented in `./src/` (e.g., `src/hle_extra.cpp`).

### LAW 3 (Never Hand-Edit `src/gen/`)
`src/gen/` is machine-generated by `./ps3recomp/tools/ppu_lifter.py` and `spu_lifter.py`.
- Never hand-edit files in `src/gen/`.
- Never read `src/gen/recomp_*.cpp` into LLM context windows (these files can be hundreds of thousands of lines long).
- Inspect line, function, or symbol counts via CLI only (e.g., `Get-Content`, `Select-String`, or Python scripts).

### LAW 4 (Windows Host & 45 GB Disk Guardrail)
All automation scripts in `./tools/` must be cross-platform Python (`.py`) or PowerShell (`.ps1`), never Bash-only.
- In `CMakeLists.txt`, compile `src/gen/recomp_*.cpp` in Release mode (`-O2` / `/O2`) without `/Zi` full PDB symbols to prevent exhausting the ~45 GB of free disk space on `C:`.
- Monitor disk usage before and after generating code or running builds.

### LAW 5 (Gemini Flash 3.8 High Planner & Executor)
`Gemini Flash 3.8 High` operates as both Planner and Executor for GSD workflows.
- Every task in `PLAN.md` must include exact Windows CLI commands, exact relative paths (`./ps3recomp/...`), and a deterministic `<verify>` command.
- Do not emit vague instructions. Executors must be able to run and verify each step deterministically without guessing.
