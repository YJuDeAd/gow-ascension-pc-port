# Plan 10-02: `libedgegeom` SPU Geometry Vertex Format & Input Layout Mapping Audit

## Goal
Audit `NV4097_SET_VERTEX_DATA_ARRAY_FORMAT` and `NV4097_SET_VERTEX_DATA_ARRAY_OFFSET` in the live command stream to ensure half-float (`F16`), compressed normal (`CMP` / `DEC3N`), and unsigned byte (`UB`) vertex formats emitted by `Wws_Job/MeshProcJobs` (`wid=14`) map to exact matching `DXGI_FORMAT` values in the D3D12 Input Layout.

---

## Task 1: Audit Vertex Attribute Decoding Pipeline
- Verify `rsx_vertex_formats.h` and `rsx_vertex_compact.h` mappings for `RSX_VERTEX_TYPE_F`, `RSX_VERTEX_TYPE_SF`, `RSX_VERTEX_TYPE_UB`, `RSX_VERTEX_TYPE_UB256`, `RSX_VERTEX_TYPE_CMP`, and `RSX_VERTEX_TYPE_S1`.
- Confirm `rsx_to_dxgi_format` maps `F16` (`SF`) to `DXGI_FORMAT_R16G16B16A16_FLOAT` / `R16G16_FLOAT`, `UB` to `DXGI_FORMAT_R8G8B8A8_UNORM`, and `F` to `DXGI_FORMAT_R32G32B32A32_FLOAT`.

### Verify Command
```powershell
Select-String -Path ps3recomp\libs\video\rsx_vertex_formats.h -Pattern "DXGI_FORMAT" | Select-Object -First 15
```

---

## Task 2: Verify `MeshProcJobs` DMA Vertex Writebacks
- Check `Wws_Job/MeshProcJobs` (`wid=14`) DMA operations writing decompressed vertex buffers into guest memory.
- Verify D3D12 LiveDraw vertex buffer bindings consume these buffers without vertex explosion or stride mismatch.

### Verify Command
```powershell
Select-String -Path build\run_port_stderr.log -Pattern "wid=14|DMA.*ea=0x011|NV4097_SET_VERTEX" | Select-Object -First 15
```
