# Plan 10-01: D3D12 Deferred Shading G-Buffer Render-Target-to-Texture Aliasing & Transition Verification

## Goal
Verify that D3D12 LiveDraw tracks offscreen RSX color/depth targets (`NV4097_SET_SURFACE_COLOR_*OFFSET` and `ZETA_OFFSET`) and transitions them to `D3D12_RESOURCE_STATE_PIXEL_SHADER_RESOURCE` when sampled as textures via `NV4097_SET_TEXTURE_OFFSET` during deferred shading passes.

---

## Task 1: Enable Render-Target Aliasing Diagnostics
- Enable `$env:LD_ALIAS_DBG = "1"` in `tools/run_port.ps1`.
- Verify `rsx_live_draw.c` sampler key regression test passes.

### Verify Command
```powershell
python ./ps3recomp/tools/test_live_draw_sampler_key.py
```

---

## Task 2: Verify Render Target Surface Allocation & Texture Sampling
- Run `tools/run_port.ps1 -LiveDraw -TimeoutSeconds 30`.
- Verify in `build/run_port_stderr.log` that:
  1. Render target surfaces are created via `surface_get` (`[surfsz] new live surface`).
  2. Textures sampling prior render targets report alias binding hits or feedback SRVs (`g_ld_bind_surf`).

### Verify Command
```powershell
Select-String -Path build\run_port_stderr.log -Pattern "\[surfsz\]|\[alias-hit\]|display buffer" | Select-Object -First 20
```
