# Plan 10-03: Live RSX Draw Call Execution, Display Surface Presentation & Metrics Logging

## Goal
Execute live RSX rendering passes in D3D12, capture draw call metrics (`DRAW_ARRAYS` / `DRAW_INDEX_ARRAY`), verify triple-buffered display surface presentation, and document all metrics in `./docs/bringup-status.md` and `.planning/STATE.md`.

---

## Task 1: Execute Port with LiveDraw & Capture Render Metrics
- Run `tools/run_port.ps1` with `-LiveDraw -TimeoutSeconds 30`.
- Capture:
  1. Active surface count (`surfaces=%u zetas=%u textures=%u psos=%u`).
  2. Frame presentation count (`_cellGcmSetFlipCommand` and swapchain flips).
  3. Reference fences drained across pushbuffer chunks.

### Verify Command
```powershell
powershell -ExecutionPolicy Bypass -File .\tools\run_port.ps1 -LiveDraw -TimeoutSeconds 30
```
