### Task 2: Configure Automated Pad Injection in Launch Profile
Update `tools/run_port.ps1` to configure `$env:YDKJ_INJECT_PAD = "1"`, `$env:YDKJ_PAD_BTN = "0x0008"` (CELL_PAD_CTRL_START), and `$env:YDKJ_PAD_DELAY = "5"` so automated test runs pulse START to advance past the initial title screen.

```powershell
python -c "
path = 'tools/run_port.ps1'
content = open(path, 'r', encoding='utf-8').read()
if 'YDKJ_INJECT_PAD' not in content:
    content = content.replace(
        '\$env:SPU_INTERP_UNLIFTED = \"1\"',
        '\$env:SPU_INTERP_UNLIFTED = \"1\"\n    \$env:YDKJ_INJECT_PAD = \"1\"\n    \$env:YDKJ_PAD_BTN = \"0x0008\"\n    \$env:YDKJ_PAD_DELAY = \"5\"'
    )
    open(path, 'w', encoding='utf-8', newline='\n').write(content)
    print('Added automated pad injection configuration to tools/run_port.ps1')
else:
    print('Pad injection already configured in tools/run_port.ps1')
"
```

<verify>
`Get-Content tools/run_port.ps1 | Select-String "YDKJ_INJECT_PAD"`
</verify>
