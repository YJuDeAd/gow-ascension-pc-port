# Plan 08-02: Vertex Attribute Endianness & D3D12 Geometry Drawing

**Phase:** 08-edgegeom-and-input  
**Plan:** 08-02  
**Goal:** Verify vertex attribute layout, strides, and endianness for `libedgegeom` output, and validate D3D12 3D mesh rasterization.

---

### Task 1: Audit D3D12 Vertex Compact Decoding Configuration
Verify that the RSX live-draw backend configures `C-compact` vertex decoding mode with full feature flags (`0x7`) to support edge geometry formats.

```powershell
python -c "
stderr = open('build/run_port_stderr.log', 'r', encoding='utf-8', errors='ignore').read()
assert '[rsx-vertex] mode=C-compact features=0x7' in stderr, 'Expected C-compact vertex decoder'
print('VERIFIED: D3D12 C-compact vertex decoding active')
"
```

<verify>
`Get-Content build/run_port_stderr.log | Select-String "\[rsx-vertex\] mode=C-compact"`
</verify>

---

### Task 2: Validate Vertex Input Layout Formats
Audit `ps3recomp/libs/video/rsx_vertex_compact.c` and `rsx_live_draw.c` to confirm that standard `libedgegeom` vertex streams (position, normal, texcoord) map to valid DXGI formats.

```powershell
python -c "
c = open('ps3recomp/libs/video/rsx_vertex_compact.c', 'r', encoding='utf-8', errors='ignore').read()
assert 'dc_vertex_attr_canonical' in c, 'Expected canonical vertex attribute helper'
print('VERIFIED: Vertex attribute canonical mapping exists in runtime')
"
```

<verify>
`Get-Content ps3recomp/libs/video/rsx_vertex_compact.c | Select-String "dc_vertex_attr_canonical"`
</verify>

---

Run `run_port.ps1` with `-LiveDraw -TimeoutSeconds 15` and check stderr for non-zero draw calls and pipeline state objects.
