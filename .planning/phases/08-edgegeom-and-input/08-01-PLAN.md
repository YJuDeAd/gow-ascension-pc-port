### Task 2: Validate DMA Writeback Offsets & GCM Memory Aperture Target
Audit SPU DMA `mfc_put` / `mfc_putl` commands emitted during `MeshProcJobs` to ensure all destination effective addresses land within the mapped 82 MB IO aperture (`0x11000000 .. 0x16200000`).

```powershell
python -c "
import re
stderr = open('build/run_port_stderr.log', 'r', encoding='utf-8', errors='ignore').read()
dmas = re.findall(r'\[spurs-pm\] DMA cmd=0x40.*ea=0x([0-9A-Fa-f]+)', stderr)
print(f'Total SPU DMA transfers recorded: {len(dmas)}')
for ea_hex in dmas[:10]:
    ea = int(ea_hex, 16)
    print(f'  DMA target EA: 0x{ea:08X}')
"
```

<verify>
`Get-Content build/run_port_stderr.log | Select-String "\[spurs-pm\] DMA"`
</verify>
