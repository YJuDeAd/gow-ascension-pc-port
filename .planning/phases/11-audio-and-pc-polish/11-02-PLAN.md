# Plan 11-02: Configuration System (config.toml), Frame Pacing & Resolution Scaling

## Goal
Expose native PC resolution scaling (`1280x720` up to `2560x1440` / `3840x2160`), VSync toggle, audio parameters, and controller deadzone settings in `./config.toml`, and wire the port runner to parse configuration settings automatically.

---

## Task 1: Create Root `config.toml`
- Create `./config.toml` in the project root defining:
  - `[graphics]`: `width = 1280`, `height = 720`, `vsync = "on"`, `backend = "d3d12"`, `scale_factor = 1`
  - `[audio]`: `backend = "wasapi"`, `sample_rate = 48000`, `buffer_size = 512`, `channels = 8`, `downmix = "stereo"`
  - `[input]`: `backend = "xinput"`, `deadzone = 7849`, `keyboard_fallback = true`
  - `[spu]`: `spu_interpreter_unlifted = true`, `spu_host_depth_max = 100000`
  - `[debug]`: `log_audio_rate = true`, `log_audio_peak = true`, `live_draw = true`

### Verify Command
```powershell
Test-Path .\config.toml
```

---

## Task 2: Wire `tools/run_port.ps1` to Parse `config.toml`
- Update `tools/run_port.ps1` to detect `./config.toml`, extract graphics dimensions (`width`, `height`), audio flags, and controller settings, and export `$env:GOW_RSX_W`, `$env:GOW_RSX_H`, `$env:AUDIO_RATE`, etc.
- Support runtime resolution overrides (e.g., `-Width 2560 -Height 1440` or from `config.toml`).

### Verify Command
```powershell
powershell -Command "if (Test-Path .\config.toml) { Get-Content .\config.toml | Select-String 'width|height|deadzone' }"
```

---

## Task 3: Verify Resolution Scaling & Frame Presentation
- Run `tools/run_port.ps1 -LiveDraw -TimeoutSeconds 15` with 1440p / 4K resolution configured or tested.
- Verify in `build/run_port_stderr.log` that the D3D12 LiveDraw backend initializes at the scaled resolution and presents frames cleanly.

### Verify Command
```powershell
Select-String -Path build\run_port_stderr.log -Pattern "live-draw|backend init|display buffer" | Select-Object -First 10
```
