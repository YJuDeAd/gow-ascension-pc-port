# Plan 06-01: Wws_Job Policy Module Extraction, Wrapping & Clean Lifter Pipeline

**Phase:** 06-wws-job-spu-workloads  
**Plan:** 06-01  
**Goal:** Extract the 12,288-byte SPU Policy Module at guest address `0x0077CA80` from `EBOOT.ELF`, wrap it into an SPU ELF, lift it into C++, and debase relative include headers.

### Task 1: Extract Raw 12,288-Byte SPU Policy Module Binary
Extract the 12,288-byte binary block from file offset `0x0076CA80` (`guest EA 0x0077CA80 - 0x10000 segment vaddr`) of `./vfs/PS3_GAME/USRDIR/EBOOT.ELF` into `./spu_programs/wws_job_pm.bin`.

```powershell
python -c "
with open('vfs/PS3_GAME/USRDIR/EBOOT.ELF', 'rb') as f:
    f.seek(0x0077CA80 - 0x10000)
    data = f.read(12288)
assert len(data) == 12288, f'Expected 12288 bytes, got {len(data)}'
import os
os.makedirs('spu_programs', exist_ok=True)
with open('spu_programs/wws_job_pm.bin', 'wb') as f:
    f.write(data)
print('Extracted spu_programs/wws_job_pm.bin (12,288 bytes)')
"
```

### Task 3: Verify FNV-1a-64 Fingerprint Matches Runtime `0xC8D774963A96DCF2`
Validate that the executable text segment fingerprint of `spu_programs/wws_job_pm.elf` matches the runtime fingerprint reported by `cellSpurs` in Phase 5.

```powershell
python -c "
def be16(b, o): return (b[o] << 8) | b[o + 1]
def be32(b, o): return (b[o] << 24) | (b[o + 1] << 16) | (b[o + 2] << 8) | b[o + 3]
def fnv1a64(b):
    h = 1469598103934665603
    for x in b: h = ((h ^ x) * 1099511628211) & 0xFFFFFFFFFFFFFFFF
    return h
b = open('spu_programs/wws_job_pm.elf', 'rb').read()
phoff, phes, phn = be32(b, 0x1C), be16(b, 0x2A), be16(b, 0x2C)
for i in range(phn):
    o = phoff + i * phes
    if be32(b, o) == 1 and be32(b, o + 0x18) & 1:
        off, fsz = be32(b, o + 4), be32(b, o + 0x10)
        fp = fnv1a64(b[off:off + fsz])
        print(f'Computed text_fp: 0x{fp:016X}')
        assert fp == 0xC8D774963A96DCF2, f'Fingerprint mismatch: {hex(fp)}'
        print('VERIFIED: fingerprint matches 0xC8D774963A96DCF2 exactly!')
"
```

### Task 5: Debase Relative Include Paths
Rewrite the relative include paths in `./src/gen/spu/wws_job_pm/spu_recomp.h` and `./src/gen/spu/wws_job_pm/spu_recomp.c` to bare `#include "spu_context.h"` so the lifted code resolves against the runtime include path.

```powershell
python -c "
import re
for p in ['src/gen/spu/wws_job_pm/spu_recomp.h', 'src/gen/spu/wws_job_pm/spu_recomp.c']:
    txt = open(p, 'r', encoding='utf-8').read()
    txt = re.sub(r'#include\s+\"(?:\.\./)+runtime/spu/([A-Za-z0-9_]+\.h)\"', r'#include \"\1\"', txt)
    open(p, 'w', encoding='utf-8', newline='\n').write(txt)
print('Debased includes in wws_job_pm sources.')
"
```

<verify>
`python -c "h=open('src/gen/spu/wws_job_pm/spu_recomp.h').read(); assert '#include \"spu_context.h\"' in h; print('VERIFIED: include debasing successful')"`
</verify>
