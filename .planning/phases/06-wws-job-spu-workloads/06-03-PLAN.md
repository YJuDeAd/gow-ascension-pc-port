### Task 2: Verify Elimination of `PM NOT LIFTED` Warnings
Inspect `build/run_port_stdout.log` to verify that `wid=8 PM NOT LIFTED (fp=0xC8D774963A96DCF2 size=12288)` is completely gone, and that all five workloads (`wid=8`, `wid=9`, `wid=10`, `wid=13`, `wid=14`) are resolved to `image=5`.

```powershell
python -c "
stdout = open('build/run_port_stdout.log', 'r', encoding='utf-8', errors='ignore').read()
assert 'PM NOT LIFTED (fp=0xC8D774963A96DCF2' not in stdout, 'FAILURE: PM NOT LIFTED still found in log!'
assert 'wid=8 PM resolved' in stdout or 'wid=8' in stdout, 'FAILURE: wid=8 not found in log!'
print('VERIFIED: All PM NOT LIFTED warnings eliminated for fp=0xC8D774963A96DCF2!')
"
```

<verify>
`Get-Content build/run_port_stdout.log | Select-String "PM NOT LIFTED" | Measure-Object | ForEach-Object { if ($_.Count -eq 0) { Write-Host "VERIFIED: 0 PM NOT LIFTED warnings" } else { Write-Error "Found $($_.Count) warnings" } }`
</verify>
