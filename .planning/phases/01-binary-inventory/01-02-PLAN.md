  <action>
Verify that `./tools/find_code_end.py` exists and is executable. The script reads the 64-bit Big-Endian ELF header and section headers, locates all sections with `SHF_EXECINSTR` (executable instructions), identifies the final executable section (`.text`), and computes its ending boundary (`addr + size`).
Run:
```powershell
python ./tools/find_code_end.py ./vfs/PS3_GAME/USRDIR/EBOOT.ELF
```
Verify that the output identifies:
- Last executable section: `.text` ending at `0x0062C4CC`
- First read-only data section: `.rodata` starting immediately after
- Recommended `--code-end` boundary: `0x0062C4CC`
  </action>
  <verify>
```powershell
$output = python ./tools/find_code_end.py ./vfs/PS3_GAME/USRDIR/EBOOT.ELF
$matched = $output | Select-String "Recommended --code-end boundary: 0x0062C4CC"
if ($matched) {
    Write-Host "VERIFY_CODE_END_SUCCESS: $matched"
} else {
    Write-Error "Failed to find 0x0062C4CC code-end boundary"
}
```
  </verify>
  <done>tools/find_code_end.py outputs exactly 0x0062C4CC as the code-end boundary.</done>
