  <files>
    ps3recomp/build/libps3recomp_runtime.a

  </files>
  <action>
Configure CMake in `./ps3recomp` targeting `./ps3recomp/build` with Ninja generator and Release build type.
Per LAW 2, do NOT modify any source files in `./ps3recomp/`.
Run:
```powershell
cmake -S ./ps3recomp -B ./ps3recomp/build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build ./ps3recomp/build
```
On Windows with LLVM-MinGW/Clang, CMake produces `libps3recomp_runtime.a`. Create a copy named `ps3recomp_runtime.lib` in `./ps3recomp/build/` to support both MinGW and MSVC/clang-cl linkers:
```powershell
if (Test-Path ./ps3recomp/build/libps3recomp_runtime.a) {
    Copy-Item ./ps3recomp/build/libps3recomp_runtime.a ./ps3recomp/build/ps3recomp_runtime.lib -Force
}
```
  </action>
  <verify>
```powershell
if ((Test-Path ./ps3recomp/build/libps3recomp_runtime.a) -or (Test-Path ./ps3recomp/build/ps3recomp_runtime.lib)) {
    $item = Get-Item ./ps3recomp/build/*ps3recomp_runtime*
    Write-Host "VERIFY_RUNTIME_SUCCESS: Found $($item.FullName) ($($item.Length) bytes)"
} else {
    Write-Error "Runtime build artifact not found"
}
```
  </verify>
  <done>ps3recomp runtime compiles cleanly into ps3recomp/build/ and produces a valid non-empty archive (~2.5 MB).</done>
</task>
