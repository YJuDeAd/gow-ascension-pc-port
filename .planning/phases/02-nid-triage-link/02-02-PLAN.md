   - `cellSpursInitializeWithAttribute2` -> forwards to `cellSpursInitializeWithAttribute`
   - `cellSpursCreateTaskset2` -> forwards to `cellSpursCreateTaskset`
   - `cellSpursCreateTask2` -> forwards to `cellSpursCreateTask`

   - `cellSpursAttributeEnableSystemWorkload` (0x9DCBCB5D) -> `CELL_OK`
2. **FIOS Concurrency Fix:**
   - `sys_lwcond_create`: replicates the 32-bit EA pointer into both 32-bit halves of the 64-bit struct, eliminating FIOS invalid-mutex deadlocks.
3. **One-Time Initialization:**
   - `sys_ppu_thread_once`: executes the game's initialisation OPD once under a thread mutex.
4. **Network & System Shims:**
   - `cellNetCtlGetState`: writes `CELL_NET_CTL_STATE_IP_OBTAINED = 3` and returns `CELL_OK`.
   - `cellFsReadWithOffset` & `cellFsWriteWithOffset`: file I/O offset helpers.
   - `cellVideoOutGetDeviceInfo`: advertises 720p / 1080p display modes.
5. **Registration Function:**
   - Exposes `void ascension_hle_register(void);` (and alias `gow_hle_register_extra`) registering all handlers via `ps3_hle_register_ctx()`.

Create `src/main.cpp` modeled on `twistedmetal/src/boot_main.cpp`:
1. Include `ppu_recomp.h`, standard headers, and Windows SEH headers.
2. Define crash filter (`gow_crash_filter`) logging ExceptionCode, ExceptionAddress, `g_last_hle_nid`, `g_last_hle_name`, guest registers (`ctr`, `lr`, `r3`), and RVA for symbolization.
3. Define `main(int argc, char** argv)`:
   - Sets Windows unhandled exception filter.
   - Configures default VFS root: `ppu_vfs_root = "./vfs"`.
   - Resolves target ELF path (defaulting to `./vfs/PS3_GAME/USRDIR/EBOOT.ELF` or argv[1]).
   - Calls `ppu_load_elf(elf_path)` -> retrieves entry OPD.
   - Calls `ppu_recomp_register()` -> registers 19,570 lifted functions.
   - Calls `ppu_hle_init()` -> initializes NID table.
   - Calls `ppu_sysprx_register()` -> registers CRT / sysPrx.
   - Calls `ppu_fs_register()` -> registers VFS filesystem.
   - Calls `gow_psn_stubs_register()` -> registers offline PSN/multiplayer stubs.
   - Calls `ascension_hle_register()` -> registers SPURS v2 and single-player HLE bridges.
   - Invokes `ppu_run(entry_opd, stack_top)` to begin native guest execution.
