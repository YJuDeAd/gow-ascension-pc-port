# Plan 09-03: Scaleform 3D Main Menu Presentation & Pad Input Navigation

## Goal
Verify that the 1280x720 Direct3D 12 swapchain receives Scaleform UI draw packets from `SHELL.PSARC`, renders the God of War: Ascension 3D Main Menu, and responds to gamepad input (`CELL_PAD_CTRL_CROSS` / `START`) injected via `YDKJ_INJECT_PAD=1`.

---

## Task 1: Verify RSX LiveDraw Presentation of Main Menu UI
- Launch `gow_ascension.exe` with `-LiveDraw` profile for 30 seconds.
- Inspect `build/run_port_stderr.log` and `build/run_port_stdout.log` for active swapchain flip updates (`cellGcmTickFlip`), reference fence draining, and `DRAW_INDEX_ARRAY` / `DRAW_ARRAYS` packet processing.

### Verify Command
```powershell
Select-String -Path build\run_port_stderr.log -Pattern "\[live-draw\]|drained fence|flip" | Select-Object -Last 20
```

---

## Task 2: Verify Gamepad Input Injection & Menu Navigation
- Verify that `cellPad` receives simulated `CELL_PAD_CTRL_START` (`0x0008`) and `CELL_PAD_CTRL_CROSS` (`0x0040`) button events after the title logo sequence.
- Document phase results in `09-01-SUMMARY.md`, `09-02-SUMMARY.md`, `09-03-SUMMARY.md`, `docs/bringup-status.md`, and `.planning/STATE.md`.

### Verify Command
```powershell
Select-String -Path build\run_port_stdout.log, build\run_port_stderr.log -Pattern "cellPad|inject" | Select-Object -Last 10
```
