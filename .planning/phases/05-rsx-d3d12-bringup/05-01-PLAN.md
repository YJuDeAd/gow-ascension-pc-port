<task type="auto">
  <name>Task 1: Add -LiveDraw Launch Profile to tools/run_port.ps1</name>
  <files>
    tools/run_port.ps1
  </files>
  <action>
Update `tools/run_port.ps1` to accept a `[switch]$LiveDraw` parameter.
When `-LiveDraw` is specified:
1. Set `$env:RSX_LIVE_DRAW = "1"` (activates live D3D12 pipeline).
2. Set `$env:GCM_RECDBG = "1"` (records last RSX FIFO commands and decode chains).
3. Set `$env:GCM_REFLOG = "1"` (records reference marker and fence updates).
4. Set `$env:LD_TRACE_PSO = "1"` (traces pipeline state object compilation).
5. Set `$env:GCM_SEMA_ACQUIRE = "0"` (ensures safe non-blocking semaphore pass).
6. Log all active RSX environment variables prior to launching `gow_ascension.exe`.
  </action>
  <verify>
```powershell
python -c "
txt = open('tools/run_port.ps1', encoding='utf-8').read()
assert 'LiveDraw' in txt
assert 'RSX_LIVE_DRAW' in txt
assert 'GCM_RECDBG' in txt
print('VERIFY_LIVEDRAW_PROFILE_OK')
"
```
  </verify>
  <done>tools/run_port.ps1 supports -LiveDraw profile with RSX diagnostic flags.</done>
</task>
