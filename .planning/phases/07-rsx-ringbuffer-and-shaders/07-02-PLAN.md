### Task 2: Validate RSX JUMP/CALL Target Offsets
Analyze `build/run_port_stderr.log` for any invalid JUMP (`type=1`) or CALL (`type=2`) destinations, ensuring all branch targets lie within the mapped IO range `0x00000000 .. 0x05200000`.

```powershell
python -c "
import re
stderr = open('build/run_port_stderr.log', 'r', encoding='utf-8', errors='ignore').read()
jumps = re.findall(r'\[JMP\]\s+([0-9A-Fa-f]+)\s+->\s+([0-9A-Fa-f]+)', stderr)
print(f'Detected {len(jumps)} JUMP instructions in stderr trace:')
for src, dst in jumps:
    dst_val = int(dst, 16)
    mapped = dst_val < 0x05200000
    print(f'  JUMP from 0x{src} -> 0x{dst} (mapped: {mapped})')
"
```

<verify>
`Get-Content build/run_port_stderr.log | Select-String "\[JMP\]"`
</verify>
