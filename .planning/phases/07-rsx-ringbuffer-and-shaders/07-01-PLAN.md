# Plan 07-01: Big Ring Buffer (BrB) FIFO Flow & SPU Recursion Depth Tuning

**Phase:** 07-rsx-ringbuffer-and-shaders  
**Plan:** 07-01  
**Goal:** Tune SPU host depth limits, trace Big Ring Buffer (`BrB`) command chunk population at `0x00014000` and `0x00132040+`, and eliminate unmapped JUMP stalls.

---

### Task 1: Configure SPU Host Depth Max in Launch Harness
Update `./tools/run_port.ps1` to set `$env:SPU_HOST_DEPTH_MAX = "100000"` in the `-LiveDraw` profile so deep SPU job chains in `Wws_Job` do not trip the default 2,000-depth recursion guard.

```powershell
python -c "
path = 'tools/run_port.ps1'
content = open(path, 'r', encoding='utf-8').read()
if 'SPU_HOST_DEPTH_MAX' not in content:
    content = content.replace(
        '\$env:GCM_SEMA_ACQUIRE = \"0\"',
        '\$env:GCM_SEMA_ACQUIRE = \"0\"\n    \$env:SPU_HOST_DEPTH_MAX = \"100000\"'
    )
    open(path, 'w', encoding='utf-8', newline='\n').write(content)
    print('Added SPU_HOST_DEPTH_MAX=100000 to tools/run_port.ps1')
else:
    print('SPU_HOST_DEPTH_MAX already configured in tools/run_port.ps1')
"
```

<verify>
`Get-Content tools/run_port.ps1 | Select-String "SPU_HOST_DEPTH_MAX"`
</verify>

### Task 3: Verify Big Ring Buffer (`BrB`) SPU Execution
Analyze `build/run_port_stderr.log` to confirm that `Wws_Job` SPU worker threads execute past `host_depth=2000` without halting, and inspect the status of the `0x00014000` JUMP packet.

```powershell
python -c "
stderr = open('build/run_port_stderr.log', 'r', encoding='utf-8', errors='ignore').read()
assert 'lifted call recursion, halting the SPU' not in stderr, 'WARNING: SPU depth tripped!'
print('VERIFIED: SPU worker threads advanced without tripping host depth guard')
"
```

<verify>
`Get-Content build/run_port_stderr.log | Select-String "lifted call recursion" | Measure-Object | ForEach-Object { if ($_.Count -eq 0) { Write-Host "VERIFIED: 0 depth guard aborts" } else { Write-Error "Found aborts" } }`
</verify>
